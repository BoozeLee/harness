# Security Policy

## Reporting a Vulnerability

If you find a security issue in this repository, please report it privately rather
than opening a public issue.

- Email: bakerstreetbandit@zohomail.eu
- GitHub: use "Report a vulnerability" on the Security tab of this repository

Please include: affected file/commit, reproduction steps, and impact. I aim to
acknowledge within 72 hours and to ship a fix or mitigation within 14 days.

## Scope

This is a solo-maintained personal project. There are no production deployments and
no hosted service. Reports about code correctness in a local research/eval harness
are welcome but are not vulnerabilities per se.

## Supported Versions

Only the current `main` branch is maintained.
